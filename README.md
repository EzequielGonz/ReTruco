# ReTruco - Mejor Juego de Truco Online

## 🎴 Características

### Diseño Premium
- Animaciones fluidas con Framer Motion
- Efectos visuales de casino
- Interfaz responsive y moderna
- Glassmorphism y gradientes elegantes

### Juego Completo de Truco Argentino
- Mazo de 40 cartas españolas con diseños SVG realistas
- Todas las reglas implementadas:
  - Truco / Retruco / Vale Cuatro
  - Envido / Real Envido / Falta Envido
  - Flor / Contra Flor
  - Sistema de puntos (15 o 30)
- IA avanzada del bot
- Modo multijugador (próximamente)

### Escenarios Interactivos
- Mesa de juego realista
- Animaciones de cartas
- Efectos de sonido
- Sistema de logros

## 🚀 Tecnologías

- React 19 + TypeScript
- Vite
- TailwindCSS v4
- Framer Motion
- Zustand
- Socket.io (para multijugador)

## 📦 Instalación

```bash
npm install
npm run dev
```

## 📁 Estructura

```
src/
  assets/
    cards/          # SVG de cartas españolas
    images/         # Backgrounds y assets
    sounds/         # Efectos de sonido
  components/
    game/           # Componentes del juego
    ui/             # Componentes UI reutilizables
    effects/        # Efectos visuales
  pages/            # Páginas de la app
  stores/           # Estado global (Zustand)
  utils/            # Lógica del juego
  hooks/            # Custom hooks
  styles/           # Estilos globales
```
